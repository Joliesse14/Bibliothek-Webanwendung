# Library Management Web Application
A web-based library management system developed as part of a university software engeering projekt. 
## Features
- User authentication
- Book search
- Borrowing and returning books
- Library member management
## Technologies 
- Java servlet
- css
- Javascript
- MariaDB
- DOcker
- Tomcat
- Receipt
